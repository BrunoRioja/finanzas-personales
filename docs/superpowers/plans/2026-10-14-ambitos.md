# Ámbitos de gasto — Plan de implementación

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Agregar una segunda dimensión a los gastos, el **ámbito** (Personal, Diversión, Familia, Trabajo), independiente de la categoría, con selección en la app y en el bot, análisis en el Inicio y filtro en Movimientos.

**Architecture:** Hoja nueva `Ambitos` y columna `ambito_id` en `Movimientos` y `Divisiones` (esquema v5). Vacío = Personal. Las reglas puras viven en `src/core/ambitos.js` (efectivo, validación al guardar, alta/edición); la API, el dashboard, el bot y las vistas solo las consumen.

**Tech Stack:** Google Apps Script (V8) + HTML/JS sin framework; pruebas con `node --test` sobre `tests/harness.js` (servicios de Google simulados); visor de UI `tests/ui/ver.js` con `tests/ui/stub.js`.

**Spec:** [docs/superpowers/specs/2026-10-14-ambitos-design.md](../specs/2026-10-14-ambitos-design.md)

## Global Constraints

- Esquema: `VERSION_ESQUEMA = 5`. Columnas nuevas **al final**: `Movimientos.ambito_id` (texto), `Divisiones.ambito_id` (texto). Hoja nueva `Ambitos`: `id` texto, `nombre` texto, `emoji` texto, `orden` número, `activo` booleano.
- Id fijo de Personal: `'personal'`. **Vacío = Personal**; un gasto en Personal se guarda con `ambito_id` vacío. Ingresos y transferencias guardan siempre vacío.
- Iniciales: Personal 🙋 (orden 1), Diversión 🎉 (2), Familia 👨‍👩‍👧 (3), Trabajo 💼 (4).
- Personal no se puede desactivar. Ámbito inexistente al guardar → error `Ámbito inválido.`; desactivado (y no era el previo) → `El ámbito "X" está desactivado.`
- Las reglas recuerdan solo la categoría. Presupuestos, avisos, `/hoy` y `/mes` no cambian.
- Textos en español con tildes. Nada de datos reales en tests, fixtures ni stub.
- `callback_data` de Telegram ≤ 64 bytes.
- Rama `fase-ambitos` (ya creada desde `fix-revisar-guardar`, v0.7.2). Versión final 0.8.0. Commits con `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- Comandos: `npm test` (todos), `node --test tests/<archivo>.test.js` (uno), `npm run lint`.

## Review Focus

1. **Hoja instalada antes de v5 que se abre desde el bot o la app** → migra, crea los 4 ámbitos una sola vez y los movimientos existentes cuentan como Personal (Task 1, test de migración idempotente).
2. **Ámbito desactivado en un gasto viejo que se edita** → se puede guardar sin cambiarlo; en un gasto nuevo da error (Task 2).
3. **Gasto dividido en partes de ámbitos distintos** → el Inicio reparte por parte, Movimientos lo muestra con "Varios ámbitos" y aparece al filtrar por cualquiera de sus ámbitos (Tasks 3 y 6).
4. **Palabra escrita en el bot que calza con una categoría y un ámbito** (p. ej. "pers" con "Aseo personal" y "Personal") → no adivina: queda en la descripción (Task 4).
5. **Botón de ámbito tocado en un mensaje viejo** (movimiento borrado o aún por revisar) → no rompe: "Ese movimiento ya no existe." o vuelve a ofrecer categorías (Task 5).

```js
// Ámbitos de gasto: para qué se gastó (Personal, Diversión…), independiente de la categoría.
// Vacío = Personal: es la única forma en que se guarda Personal. Solo aplica a gastos.

const AMBITO_PERSONAL = 'personal';
const AMBITOS_POR_DEFECTO = [['Diversión', '🎉'], ['Familia', '👨‍👩‍👧'], ['Trabajo', '💼']];

function ambitoPersonal_() {
  return { id: AMBITO_PERSONAL, nombre: 'Personal', emoji: '🙋', orden: 1, activo: true };
}

function ambitosIniciales_() {
  return [ambitoPersonal_()].concat(AMBITOS_POR_DEFECTO.map((a, i) => ({
    id: nuevoId_(), nombre: a[0], emoji: a[1], orden: i + 2, activo: true,
  })));
}

function ordenarAmbitos_(ambitos) {
  return (ambitos || []).slice().sort((a, b) => a.orden - b.orden);
}

function ambitoEfectivo_(id, ambitos) {
  return id && (ambitos || []).some(a => a.id === id) ? id : AMBITO_PERSONAL;
}

// Lo que se escribe en Movimientos/Divisiones. Un ámbito desactivado solo vale si ya era el previo.
function ambitoParaGuardar_(tipo, ambitoId, ambitos, idsPrevios) {
  const id = String(ambitoId || '');
  if (tipo !== 'gasto' || !id || id === AMBITO_PERSONAL) return '';
  const ambito = (ambitos || []).filter(a => a.id === id)[0];
  if (!ambito) throw new Error('Ámbito inválido.');
  if (!ambito.activo && (idsPrevios || []).indexOf(id) < 0) throw new Error('El ámbito "' + ambito.nombre + '" está desactivado.');
  return id;
}

// Ámbitos efectivos de un movimiento: los de sus partes si está dividido.
function ambitosDeMovimiento_(mov, partes, ambitos) {
  if (mov.tipo !== 'gasto') return [];
  const fuente = mov.dividido && partes && partes.length ? partes : [mov];
  const ids = fuente.map(p => ambitoEfectivo_(p.ambito_id, ambitos));
  return ids.filter((id, i) => ids.indexOf(id) === i);
}

// `existentes` = ámbitos guardados; `idActual` = el que se edita ('' si es nuevo).
function normalizarAmbito_(datos, existentes, idActual) {
  const nombre = String(datos.nombre || '').trim();
  if (!nombre) throw new Error('El ámbito necesita un nombre.');
  const repetido = existentes.some(a => a.id !== idActual && normalizarTexto_(a.nombre) === normalizarTexto_(nombre));
  if (repetido) throw new Error('Ya existe el ámbito "' + nombre + '".');
  const actual = existentes.filter(a => a.id === idActual)[0];
  const orden = actual ? actual.orden : existentes.reduce((m, a) => Math.max(m, Number(a.orden) || 0), 0) + 1;
  return {
    nombre: nombre, emoji: String(datos.emoji || '').trim(), orden: orden,
    activo: idActual === AMBITO_PERSONAL || datos.activo !== false,
  };
}

// Dentro del bloqueo: llena la hoja vacía y repone Personal si alguien lo borró a mano.
function asegurarAmbitos_() {
  const actuales = leerTabla_('Ambitos');
  if (!actuales.length) {
    agregarFilas_('Ambitos', ambitosIniciales_());
  } else if (!actuales.some(a => a.id === AMBITO_PERSONAL)) {
    agregarFilas_('Ambitos', [Object.assign(ambitoPersonal_(), { orden: 0 })]);
  }
}
```

```js
// Gasto del mes por ámbito, con el detalle por categoría. Mismas reglas que gastoPorCategoria_.
function gastoPorAmbito_(lineas, ambitos, categorias, mes) {
  const grupos = {};
  lineas.forEach(l => {
    if (l.tipo !== 'gasto' || mesDe_(l.fecha) !== mes) return;
    const id = ambitoEfectivo_(l.ambito_id, ambitos);
    const g = grupos[id] || (grupos[id] = { total: 0, porCategoria: {} });
    g.total += l.monto_pen;
    g.porCategoria[l.categoria_id] = (g.porCategoria[l.categoria_id] || 0) + l.monto_pen;
  });
  const ids = Object.keys(grupos).filter(id => redondear2_(grupos[id].total) > 0);
  const total = ids.reduce((s, id) => s + grupos[id].total, 0);
  return ids.map(id => {
    const a = (ambitos || []).filter(x => x.id === id)[0] || ambitoPersonal_();
    const g = grupos[id];
    const detalle = Object.keys(g.porCategoria).filter(c => redondear2_(g.porCategoria[c]) > 0).map(c => {
      const cat = categorias.filter(x => x.id === c)[0] || SIN_CATEGORIA;
      return { categoria_id: c, nombre: cat.nombre, emoji: cat.emoji, monto: redondear2_(g.porCategoria[c]) };
    }).sort((x, y) => y.monto - x.monto);
    return {
      ambito_id: id, nombre: a.nombre, emoji: a.emoji, monto: redondear2_(g.total),
      porcentaje: Math.round(g.total / total * 100), categorias: detalle,
    };
  }).sort((x, y) => y.monto - x.monto);
}
```

```js
function abrirFormAmbito(a) {
  const v = a || { nombre: '', emoji: '', activo: true };
  const caja = abrirModal('<h2 class="titulo-modal">' + (a ? 'Editar ámbito' : 'Nuevo ámbito') + '</h2>' +
    '<div class="dos-col" style="grid-template-columns:1fr 80px">' +
      campo('Nombre', '<input class="entrada" id="b-nombre" value="' + esc(v.nombre) + '">') +
      campo('Emoji', '<input class="entrada" id="b-emoji" maxlength="8" value="' + esc(v.emoji) + '">') +
    '</div>' +
    (a && a.id !== 'personal' ? '<label class="check"><input type="checkbox" id="b-activo"' + (v.activo ? ' checked' : '') + '> Ámbito activo (desactivarlo lo oculta al registrar, pero conserva el historial)</label>' : '') +
    '<div class="acciones"><button type="button" class="boton" id="b-cancelar">Cancelar</button><button type="button" class="boton primario" id="b-guardar">Guardar</button></div>');
  $('#b-cancelar', caja).onclick = cerrarModal;
  $('#b-guardar', caja).onclick = async e => {
    const activo = $('#b-activo', caja);
    e.target.disabled = true;
    try {
      await api('guardarAmbito', { id: a ? a.id : '', nombre: $('#b-nombre', caja).value, emoji: $('#b-emoji', caja).value, activo: activo ? activo.checked : true });
      cerrarModal();
      aviso('Ámbito guardado');
      mostrar('ajustes');
    } catch (err) {
      aviso(err.message, true);
      e.target.disabled = false;
    }
  };
}
```
